Technical Specifications

Dimensions
Exactly 1200 x 630 pixels (Facebook/LinkedIn standard)
File Format
PNG (save as public/og-image.png)
Background
Dark theme: #0D0D1A (same as app background)

Layout Elements

Left Half (50% width)
- App logo (circular or rounded square)
- "King Data Visualizer" in gold Orbitron font
- "by Jeme Beseka" in smaller, lighter text below
Right Half (50% width)
- Screenshot of the dark mode histogram chart
- Use actual file: src/assets/screenshots/dark-mode-histogram.png
- Apply subtle gradient overlay for depth
Bottom Bar (60px height)
- Gold gradient background: #FFD700 to #B8860B
- White text: "Free Download — Windows 10/11 — No Account Required"
- Bold font, centered

Color Palette

Primary Gold
#FFD700
Secondary Gold
#B8860B
Dark Background
#0D0D1A
Text Color
White for main text, #aaa for secondary

Implementation Notes

  • Use a design tool like Figma, Photoshop, or Canva to create the actual image
  • Export as high-quality PNG at 1200x630px
  • Save to public/og-image.png
  • The image is referenced in src/seo/seoConfig.js as the OG image URL
  • Ensure the final file size is under 1MB for optimal loading
